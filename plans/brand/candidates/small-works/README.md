# Small Works store icon

Generated with the built-in image tool using Tellop’s modern-v2 store media guide and the exact prompt in `prompt.json`. The approved Marketing planner, Journal and dreams, and Math adventure artwork supplied style references.

`small-works-v2.png` is the unchanged generated master. The app uses `public/store-picture.webp`, a 256 × 256 still WebP, 7,848 bytes, with no metadata. It was produced by Tellop’s store-logos pipeline at quality 0.92 and passes `storeWebpProblem`. Source and output digests are copied from the pipeline into `lib/content/asset-provenance.json`.

The source artwork stays under `plans/` so the app’s portable export includes the small WebP without including design masters. `pipeline-record.json` is the unmodified output of the logo pipeline, run in an isolated staging tree. Its source path `brand/store-apps/modern-v2/small-works.png` maps to this master, and its output path `store-apps/small-works/public/store-picture.webp` maps to the app’s public asset. No Tellop listing was published.

Reviewed at full size, 48 pixels, and 72 pixels beside the approved family on light and dark surfaces.
